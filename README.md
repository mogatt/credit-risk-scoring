# Credit Risk Scoring

Модель оценки кредитного риска заемщиков: анализ факторов, сравнение алгоритмов машинного обучения и выбор порога классификации с учетом стоимости ошибок для банка.

## О проекте

Задача проекта — определить, относится ли заемщик к категории надежных или рискованных клиентов.

В работе сравниваются несколько моделей классификации. Итоговая модель выбирается не только по стандартным ML-метрикам, но и по бизнес-критерию: выдача кредита ненадежному заемщику считается более дорогой ошибкой, чем отказ надежному клиенту.

| Параметр             | Значение               |
| -------------------- | ---------------------- |
| Тип задачи           | Бинарная классификация |
| Целевая переменная   | `credit_risk`          |
| Обучающая выборка    | 750 заемщиков          |
| Тестовая выборка     | 250 заемщиков          |
| Количество признаков | 20                     |
| Валидация            | 5-fold Stratified OOF  |
| Итоговая модель      | Random Forest          |
| Порог решения        | 0.47                   |

## Данные

Используется разделенная на обучающую и тестовую части 
Датасет содержит сведения о кредитной истории, размере и сроке кредита, занятости, накоплениях, возрасте, жилищных условиях и других характеристиках заемщиков.

Целевая переменная:

* `0` — заемщик с повышенным кредитным риском;
* `1` — надежный заемщик.

Файлы проекта:

* `train_3dz.csv` — обучающая выборка с целевой переменной;
* `test_3dz.csv` — тестовая выборка без целевой переменной.

Тестовая выборка не используется при обучении моделей, настройке гиперпараметров или выборе порога. Она применяется только для получения итогового прогноза после завершения валидации.


## Этапы работы

1. Проверка структуры и качества данных.
2. Исследовательский анализ признаков и целевой переменной.
3. Разделение признаков на числовые и категориальные.
4. Построение пайплайнов предобработки.
5. Сравнение нескольких моделей классификации.
6. Настройка гиперпараметров с помощью `GridSearchCV`.
7. Получение OOF-прогнозов на стратифицированной кросс-валидации.
8. Выбор порога классификации с учетом стоимости ошибок.
9. Обучение итоговой модели на всей обучающей выборке.
10. Формирование прогноза для тестовых данных.

## Сравниваемые модели

В проекте рассмотрены:

* Dummy Classifier;
* Logistic Regression;
* Random Forest;
* Extra Trees;
* Gradient Boosting.

Для Logistic Regression, Random Forest и Extra Trees выполнен подбор гиперпараметров.

## Итоговый результат

Лучшей моделью по принятому бизнес-критерию стала **Random Forest** с порогом вероятности риска `0.47`.

Результаты получены по OOF-прогнозам: каждый объект оценивался моделью, которая не обучалась на этом объекте.

| Метрика                          | Результат |
| -------------------------------- | --------: |
| ROC-AUC                          |     0.792 |
| PR-AUC для рискованных заемщиков |     0.600 |
| Accuracy                         |     0.764 |
| Balanced Accuracy                |     0.750 |
| Recall рискованных заемщиков     |     0.716 |
| Precision рискованных заемщиков  |     0.588 |
| F1 рискованных заемщиков         |     0.645 |

При выбранном пороге модель:

* правильно выявила 161 из 225 рискованных заемщиков;
* ошибочно одобрила 64 рискованных заемщика;
* ошибочно отклонила 113 надежных заемщиков;
* правильно одобрила 412 надежных заемщиков.

## Бизнес-логика порога

Для демонстрации бизнес-подхода используется следующая условная стоимость ошибок:

* ошибочное одобрение рискованного заемщика — `2`;
* ошибочный отказ надежному заемщику — `1`.

При таком соотношении оптимальным оказался порог `0.47`.

Итоговая условная стоимость ошибок составляет **32.13 на 100 заявок**. Доля одобренных заявок — около **63.5%**, а доля рискованных клиентов среди одобренных — около **13.4%**.

Эти стоимости являются аналитическим допущением, а не реальными финансовыми показателями конкретного банка.

## Наиболее значимые факторы

По результатам модели наибольший вклад в прогноз вносят:

* состояние расчетного счета;
* кредитная история;
* срок кредита;
* объем накоплений;
* сумма кредита;
* возраст заемщика.

Важность признака показывает его влияние на прогноз модели, но не доказывает причинно-следственную связь.

## Ограничения

* Датасет небольшой и содержит исторические данные из Германии.
* Наблюдаемое качество не следует напрямую переносить на современных заемщиков.
* Соотношение стоимости ошибок выбрано как демонстрационный бизнес-сценарий.
* Тестовая выборка не содержит целевой переменной, поэтому по ней нельзя рассчитать качество модели.
* Перед использованием в реальном кредитном процессе потребуется дополнительная проверка стабильности, калибровки вероятностей и справедливости модели.
